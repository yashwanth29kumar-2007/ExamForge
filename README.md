# ExamForge

## Intelligent DAA Question Paper Generator

ExamForge is a web-based question paper generation system designed for college examinations.

The system uses Data Structures and Algorithms concepts such as:

- Sorting
- Greedy Algorithm
- Backtracking
- Priority-based selection

It generates balanced question papers based on:

- Difficulty level
- Marks
- Number of questions
- Subject
- Unit
- Topic
- Question priority

---

## Features

### Question Bank

Manage questions with:

- Question text
- Subject
- Unit
- Topic
- Difficulty
- Marks
- Priority

### Intelligent Paper Generation

Generate question papers using:

- Easy questions
- Medium questions
- Hard questions
- Custom total marks

### Examination Details

Users can enter:

- College / University name
- Subject name
- Subject code
- Semester / Year
- Examination title
- Exam duration

### Algorithm-Based Selection

ExamForge demonstrates:

- Sorting
- Greedy selection
- Backtracking
- Algorithm trace

### PDF Generation

Generated question papers can be downloaded as PDF files.

### Paper History

Previously generated papers are stored in the system history.

## Examination Pattern

The default examination pattern is:

| Difficulty | Question Type | Marks |
|---|---|---:|
| Easy | Very Short | 2 |
| Medium | Short Answer | 4 |
| Hard | Long Answer | 6 |

Example 30-mark paper:

Easy   : 3 × 2 = 6
